# Colombo

Landing page of [colombo-am.github.io](https://colombo-am.github.io/): open data projects that make
information about Armenia transparent and reusable.

Plain static files, served by GitHub Pages from `main`. To add a project, append an entry to
`projects.json` (`url`, `repo`, and `title`, `description`, `tags` in `hy` and `en`). Each project
lives in its own repository, is served at `colombo-am.github.io/<repo>/`, and links back here.
